# Deviations

Every departure from `docs/spec.md`, numbered, with the reason. Any hand edit to code by the owner is logged here. Session 7.1 also logs where the adopted spec and the public prompts differ from the evaluation draft, `BUILD.md` and the private prompts, so that the owner sees each one.

| DEV-002 | The draft lists 14 planted bad outputs for 16 judged checks, one each, and none for TR-J4. The spec requires two per judged check (REQ-080) and adds REQ-082 for the missing ones. | Control R4 asks for two known-bad outputs per judged check. Session 7.3 is sized for the draft's count; the owner may want to resize it. | 7.1 |
