# Deviations

Every departure from `docs/spec.md`, numbered, with the reason. Any hand edit to code by the owner is logged here. Session 7.1 also logs where the adopted spec and the public prompts differ from the evaluation draft, `BUILD.md` and the private prompts, so that the owner sees each one.

| # | Departure | Reason | Logged |
| --- | --- | --- | --- |
| DEV-001 | The draft says a judge passes its planted bad outputs' test when it answers no in at least 2 of 3 runs. The spec requires 3 of 3 (REQ-080). | `STANDARD.md` control R4 says a judge must fail its known-bad outputs 3 of 3 before its scores count. The standard is the authority. | 7.1 |
| DEV-002 | The draft lists 14 planted bad outputs for 16 judged checks, one each, and none for TR-J4. The spec requires two per judged check (REQ-080) and adds REQ-082 for the missing ones. | Control R4 asks for two known-bad outputs per judged check. Session 7.3 is sized for the draft's count; the owner may want to resize it. | 7.1 |
| DEV-003 | The scoping check for trip TR-08 (one question mark, 2 to 4 options, the word "recommended" once, no currency amount) gets its own requirement, REQ-052, id TR-S1. | The draft describes these checks in prose under TR-08 and gives them no id. Without one they would have no requirement. | 7.1 |
| DEV-004 | Each public prompt gains an output contract that the private prompt does not have: fixed headings and `Pattern N:` blocks (cognitive profile); fixed part headings, tier labels and option ids such as `OPT-A` (travel method); three headed blocks and a record id in square brackets after every bullet (tailoring doctrine). | The checks are code.
